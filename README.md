# Surendar Kumar H P — Dynamic Portfolio

## Run locally
```powershell
npm install
npm run dev
```
Open http://localhost:3000

## Edit content visually
Open the website and click the pencil icon in the footer. Edit the JSON and save. The website updates immediately and saves the content in this browser's localStorage.

The content seed is `config/portfolio-content.json`. Update it to change the default content for new visitors/deployments. The in-browser editor is a local editing tool, not a secure multi-user CMS: saved edits remain in that browser only. For shared production editing, connect a database and authenticated admin API.

Resume is served from `public/Surendar_Resume.pdf`.
